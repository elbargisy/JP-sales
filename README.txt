Jamjoom Pharma Ophthalmology Portal - protected version
=======================================================

Upload
- Upload all files in this folder together, to the same folder on your web host
  (index.html, sales.html, chain.html, direct.html).
- The site must be served over HTTPS (normal for any web host today); sign-in
  uses the browser's built-in encryption, which browsers only allow on secure pages.
- Visitors open index.html and sign in. Opening sales.html, chain.html or
  direct.html directly shows nothing: their data is encrypted and is only
  unlocked after a correct sign-in.

Sign-in
- One shared username and password for everyone you give access to.
- The username and password are NOT stored in these files, so they cannot be
  read from the page source.
- "Forgot username or password?" opens the visitor's email app with a request
  addressed to mohammed.bargisy@jamjoompharma.com. Reply to them with the login.
- Signed-in visitors stay signed in until they close the browser tab or press
  "Sign out".

Changing the password or updating the data
- The files must be rebuilt with the new password or new data.
  Ask Claude to rebuild the protected portal.
